# Fluent Sakhr Dictionary

The classic Sakhr Dictionary (قاموس صخر) rebuilt as a modern Windows app:
native WinUI 3, Mica, instant search, full RTL support - the same design DNA
as Fluent Prayer Times and Fluent Vantage Toolbar.

## Status

Data extraction is in progress. The original program's English word list
(59,427 lemmas) is already extracted; the Arabic meanings are being captured
from the original program on Windows runners (see `extraction/`). The app
itself lands once the dataset is complete.
